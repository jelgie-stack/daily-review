# Value drop: the average order is smaller

Order counts held up; each order is worth less. This is almost always one of four things.

1. **Discounts.** A promotion, a coupon code that leaked, a loyalty reward that paid out, a
   price mistake. Pull discount dollars per order for yesterday vs baseline. This explains most
   value drops.
2. **Mix.** Customers bought cheaper things: fewer add-ons, smaller sizes, a cheaper category.
   Compare units sold per order and category share vs baseline.
3. **Channel mix.** If a low-ticket channel grew share (in-store vs delivery, say), AOV falls
   with no change in behaviour. The brief's channel table shows this; `channel_shift.md` has the
   rest.
4. **Pricing.** A price change took effect, a tax or fee handling changed, a rounding bug. Rare,
   but worth one query.

## Deciding

A value drop with steady volume is rarely urgent on day one unless a discount is leaking. Find
the discount first; if there is none, let it run two days before assigning it to anyone.
